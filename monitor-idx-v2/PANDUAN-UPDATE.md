# Monitor IDX v2: Cara Memperbarui Aplikasi di Ponsel

Anda sudah punya aplikasi lama yang terpasang dari GitHub Pages. Cukup timpa file lama di GitHub dengan file baru ini. Aplikasi di ponsel akan berganti tampilan sendiri; tidak perlu instal ulang.

## 1. Ganti file di GitHub (dari laptop)
1. Ekstrak `monitor-idx-v2.zip`.
2. Buka https://github.com/fauzanadziimaa1/monitor-idx, lalu klik folder **monitor-idx-app**.
3. Di dalam folder itu, klik **Add file → Upload files**.
4. Seret **isi** folder hasil ekstrak ke halaman unggah: `index.html`, `manifest.webmanifest`, `sw.js`, dan folder `icons`. Seret isinya, bukan foldernya. File lama dengan nama yang sama akan tertimpa otomatis.
5. Klik **Commit changes**. Tunggu 1–2 menit sampai centang hijau muncul di bagian atas daftar file.

## 2. Muat versi baru di ponsel
1. Pastikan ponsel tersambung ke internet.
2. Buka aplikasi **Monitor IDX**, tutup sepenuhnya (geser keluar dari daftar aplikasi terbaru), lalu buka lagi.
3. Jika tampilan lama masih muncul, ulangi langkah 2 sekali lagi.

Alamat aplikasi tetap: https://fauzanadziimaa1.github.io/monitor-idx/monitor-idx-app/

Jika ikon di layar utama masih ikon lama, hapus pintasannya lalu pasang ulang dari Chrome: menu **⋮ → Instal aplikasi**.

## Fitur
- **Beranda**: grafik pertumbuhan laba 23 emiten (ketuk batang untuk melihat emiten), jumlah per status, daftar yang perlu perhatian, ringkasan prospek Q4, dan sorotan (PER termurah, yield tertinggi, FCF terkuat, skor tertinggi).
- **Emiten**: cari kode atau nama, filter status, sektor, dan "Portofolio saya", lalu urutkan menurut skor, laba, PER, yield, atau FCF.
- **Prospek Q4**: proyek berjalan dan prediksi pendapatan serta laba Q4 2026 per emiten.
- **Analitik**: peta valuasi PER vs PBV, neraca, FCF vs dividen, dan histori dividend yield 5 tahun.
- **Detail emiten**: tab Ringkasan, Kinerja, Dividen, Proyek Q4, dan Sumber. Tombol kembali Android menutup halaman detail.
- **Tampilan**: ketuk ikon ⓘ di kanan atas untuk memilih tema Terang, Gelap, atau Ikuti sistem.
